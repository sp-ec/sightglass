# Personal Portfolio Website

> This is a personal portfolio that I will use to showcase my projects, skills, interests, and more.

## Tech Stack

- **Framework**: [Next.js, Express, React, shadcn.ui]
- **Database**: [PostgreSQL]
- **Language**: [Typescript]

## Development Guidelines

### Do
- Follow existing code patterns
- Keep functions small and focused
- Comment code only when necessary and use short, non-capitalized messages. Comments should always be above the code it is referring to.
- Always read files before editing them, to make sure you have the latest version.

### Don't 
- Add dependencies without good reason
- Skip error handling
- Use `any` type
- Leave console.logs in production code
